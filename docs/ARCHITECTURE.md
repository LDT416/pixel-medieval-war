# 模拟接口与扩展

游戏以 30 Hz 更新。模拟保存游戏像素坐标、时钟和种子，渲染器用场景单位插值。渲染开关只控制表现。地图与场景共享树木布局，农庄朝向按初始地图锁定，换旗不会旋转院门。重开会清除碰撞桶、静态障碍、特效和后勤评分。

## 当前入口

- SimWorld.reset 建立地图、编制和初始位置。Crowd.step 接受移动后的目标位置，从上帧已占用位置计算可达位置，更新实际速度、步态及下一帧空间索引。
- unitTypes 提供基础数值、编制大小和占地。roster.selectVariant 为普通入场连分配变体，独立旗手保留其原始属性。
- CampaignLogistics 周期性评估换班、恢复和执行当前命令。申请交班复用传令、库存和抵达确认。资料卡显示最近一次计算的三个候选值。
- BoardShots 在发出动作时锁定棋盘格，规定帧到来后选择该格内距离格心最近的在场角色。同距时按稳定编号决定。空格无效果，友方角色也能受影响。烟尘、抛物线和弹跳均属于演出。
- BoardSight 按天气规定可见格数，连队在选取目标和执行延迟命令时检查能见范围。司令部汇总本方能见的连队。每秒保存一次目击格坐标，记录保存十秒，跟随卡显示报告年龄。部署估计使用公开的对局规模。
- Tracers3d.observe 消费游戏事件。draw 只上传当前短划的两个端点，清晰模式才显示落点校射标签。

## 扩展接口草案

| 类型 | 持久字段 | 使用者 |
|---|---|---|
| Platform | id、锚点、朝向、移动方式、成员 id、局部挂点数组 | 舰船及固定堡台共用挂点和成员占位；世界坐标由平台变换生成 |
| StructureSegment | id、结构 id、轮廓、最大耐久、当前耐久、通行状态 | 单段围墙或建筑修复时只更新所属空间格；地图、寻路和画面共享同一状态 |
| TerrainCell | 地表材质、水深等级、桥面 id、允许的移动方式 | 步行、车辆和船只分别查询；桥上与水面保留不同的可通行层 |

后续实现时按 id 顺序处理同帧事件。保存种子、平台成员、挂点、本段耐久和通行层后，重演时校验相同的地图状态。海战、攻城与可破坏墙段目前位于设计阶段。
