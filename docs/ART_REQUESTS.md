# 兵种立绘交接单

默认图集由 fallbackSheet() 生成。测试新版图集时在网址加 `?sprites=baked`。现有近景、战损和暂停重演共用这两条入口。本地默认角色使用 W5 前的图块尺寸、锚点和原色。六个新增编制借用对应旧立绘。

| 游戏中的连队 | 临时立绘 | 新图的识别特征 |
|---|---|---|
| 法国轻步兵与英国轻步兵连 | 双方线列步兵 | 法军黄色饰物、英军轻步兵号角徽；侧面也能看清帽饰 |
| 英军第 95 来复枪连 | 英军线列步兵 | 深绿上衣、黑色皮具；烟雾前仍能辨读轮廓 |
| 波兰枪骑兵连 | 法方胸甲骑兵 | 方顶帽与双色长旗；纵向动作留足图集边缘 |
| 骠骑兵、轻骑兵连 | 双方骑兵 | 短上衣与垂挂外套；马蹄接地点与借用帧对齐 |
| 骑炮兵连 | 双方野战炮组 | 马队、炮车及乘员分别可读；挂车和展开保持一致比例 |
| 榴弹炮连 | 双方野战炮组 | 短炮管和炮架；后坐时保持轮轴稳定 |

交付 PNG 与同版本 JSON，透明底，最近邻采样。保留 Sheet、Motion、动作顺序、四个方向的索引和逐帧脚底锚点。程序版使用左右方向复用，烘焙版可为四向提供独立图块。动作包含站立、行军、奔跑、瞄准、装填、近身动作、后坐、倒地、逃跑、跪姿和跪装。以仓库当前 regiments.json 的 counts、tiles 和 groups 为准。每组 frames 数应为各动作帧数之和的四倍。

验图时选同一种子，近景连播一轮步态，再暂停逐帧检查脚底漂移、长旗裁边、炮轮跳动与相邻图块渗色。新套图交付后还需给六个编制绑定独立图集键。
