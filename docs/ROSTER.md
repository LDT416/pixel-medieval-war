# 编制与后续兵种

本版保留五个基础兵种。阵营、连队名称和基础立绘与变体编制分开。新编制在有足够连队的对局中出现，跟随资料卡显示全名。步速和近景色调按编制读取。枪骑兵与来复枪兵目前借用原有游戏动作；榴弹炮同样使用原炮组的结算。六组素材交接见 [立绘需求](ART_REQUESTS.md)。

| 后续编制 | 可玩的差异与所需能力 | 美术需求 |
|---|---|---|
| 老近卫、青年近卫 | 独立的整队速度和预备队编制 | 两组帽饰、军旗及资历徽章 |
| 近卫猎兵 | 在行军与散开间切换，改变占地 | 深色制服、轻装动作 |
| 高地团 | 军乐范围内加快恢复 | 方格裙、风笛手 |
| 民兵、普鲁士后备军 | 编队变化慢，补员容量较大 | 平民外套、各区帽色 |
| 龙骑兵 | 上马与下马，交换坐骑占位 | 双姿态、牵马图块 |
| 卡宾枪骑兵、苏格兰灰骑兵 | 重骑编制各自的马匹占地、恢复周期 | 胸甲和灰马套色 |
| 哥萨克 | 分散巡行和队伍会合 | 轻装骑手、多种马色 |
| 12 磅重炮 | 较大占地和牵引队列 | 大轮炮架、挽马 |
| 康格里夫火箭队 | 独立的发射演出及受惊坐骑动画 | 架台、火光与烟迹 |
| 工兵 | 建造、修复、清除地图结构，铺设通道 | 工具、桥板和施工动作 |
| 辎重车队 | 共享补给存量，排队装卸 | 货车各装载状态 |
| 军乐队 | 以节拍触发集合与恢复 | 鼓号乐手和节拍动作 |
