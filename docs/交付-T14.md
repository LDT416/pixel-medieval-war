> 模拟配置：24 种子（`SEEDS=24`，`SCALE=2400`），所有数字均直接引自 `docs/shots/T14/` 与 `docs/shots/T13/` 原始输出文件。

## 一、机制实现摘要

### 第一部分：骑兵（A～E 节）
1. **菱形队形（A1～A3）**：
   - 新增 `Formation = 'diamond'`（已通过 `grep` 确认 `src/client` 兜底，并登记于 `前端待办-Claude.md`）。
   - `src/sim/cavalry.ts:diamondRowCounts` 实现 `1, 3, 5, 7, ..., 5, 3, 1` 行排列（22 人为 `1-3-5-7-5-1`），连长固定在最前方尖端（slot 0），横向间距 22px、纵深 26px。发起冲锋前强制经 `form` 阶段变换为菱形。
2. **冲锋状态机与动量/方向冲击（B1～B5，C1～C3）**：
   - `Company` 新增 `chargePhase`（`form` → `walk(70)` → `trot(140)` → `gallop(200)` → `charge(235)` → `impact` → `pursue`/`rally`）与连续平滑速度 `cavSpeed`。
   - 冲击伤害按 `接触速度 / 235` 计算（`< 140` 伤害与士气打击减半）；士气冲击按来向放大：正面 ×1.0、侧面 ×1.8、后背 ×2.5；撞已成型方阵在 60px 外绕行承受射击后脱离。
   - 体力系统：连续冲锋 3 次后强制休息 `≥ 1800 tick`（仅能慢步行动）。
   - 冲后流程：目标溃散则实体追击最多 1200px（骠骑 1800px）或 300 tick 后重整；混战 `≥ 200 tick` 脱离；`rally` 回到己方战线后方 600～900px 动态集结点重整为菱形、恢复士气 `≥ 55` 后再度出击。
3. **6 种战术 AI 与骑兵变体（D、E1～E3）**：
   - 彻底移除 60% 概率跳过评估；每 30 tick 择优评估 `counter`（反冲锋）、`flank`（侧翼打击）、`pursue`（追击）、`threaten`（500px 威慑逼方阵不撞击）、`battery`（夺炮）、`screen`（己方战线侧翼外 600～1200px 巡逻）。
   - 胸甲骑兵：冲击 ×1.3、速度 ×0.95；骠骑兵（`hussar`）：速度 ×1.08、冲击 ×0.85、追击 ×1.5；枪骑兵（`lancer`）：对方阵减伤改为 ×0.45、对骑兵 ×0.9。

### 第二部分：炮兵（F～I 节）
1. **数量编制（F1～F2）**：
   - 每方火炮数 = 每千人 4～6 门（2400 人局每方 5～7 门，每连 4～6 门），增援部队按同比例计算；取消桥头拆单炮，保持炮兵连编制完整。
2. **±8° 射界与转向（G1～G6）**：
   - 每门炮新增 `u.aim`（弧度），`combat.ts:gunFire` 入口处对 `|angleDiff| > 8°` 执行硬断言（涵盖实心弹、霰弹与榴弹）。
   - 优先射界内目标；射界外 `8°～30°` 撬炮尾重瞄耗时 60～90 tick 并清零校射；`> 30°` 挂车转向耗时 ≥ 150 tick 并清零校射。
3. **6 人炮组（H1～H4）**：
   - 每门炮初始 `u.crew = 6`；命中炮位 70% 概率打死一名炮手（`crew - 1`）、30% 概率损伤炮身；装填时间 = `基础 × 6 / max(1, crew)`；`crew ≤ 2` 不可转向；`crew = 0` 哑火且敌军接触计为缴获；炮连溃散停火。
4. **榴弹炮与骑炮兵（I1～I2）**：
   - `howitzer`：高抛弹道不受低空友军限制，仅查落点 150px 友军；落地发射 `shell` 事件，经 30～60 tick 引信后发射 `burst` 事件并在半径 80px 内以 16～24 条实体射线判定破片（不分敌我）。
   - `horse_battery`：挂车/展开时间均为 45 tick，速度 ×1.6，可机动跟随骑兵。
