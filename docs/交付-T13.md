> 执行者：Gemini（与任务书 14 联合集成验证）
> 验收硬件与运行环境：AMD Ryzen 9 7945HX with Radeon Graphics，Node.js v24.19.0（Windows）
> 模拟配置：24 种子（`SEEDS=24`，`SCALE=2400`），所有数字均直接引自 `docs/shots/T13/` 原始输出文件。

## 一、机制实现摘要

1. **尺度与射程（A1～A4）**
   - `src/sim/scale.ts`：`RANGE.effective = 1000`（原 320），`RANGE.musket = 1700`（原 560），`RANGE.scatter = 1200`（原 260），`RANGE.round = 6000`（原 2500）。
   - `src/sim/maps.ts`：开局 `lineGap = rng.int(2250, 2950)`，双方战线间距拉开至 **4500～6000px**，保持地图尺寸 `16000×8000` 不变（无需扩大 `WIDTH`）。
   - `src/sim/projectiles.ts`：延续真实实体射线 `traceRay`，通过横向/纵向物理散布参数实现随距离自然衰减，未使用任何查表抽签。
2. **营级编制（B1～B6）**
   - `src/sim/arenaTypes.ts` 新增 `Battalion`、`BattalionFireMode`，`SimWorld` 新增 `battalions: Battalion[]`。
   - 新建 `src/sim/battalion.ts`：战列步兵按 4～6 连编营、近卫掷弹兵按 3～5 连编营；横队状态下各连左右紧挨（期望净间隙 `16px ≤ 30px`，前后错位 `0px ≤ 40px`），统一营朝向、营级选目标，某连溃散后自动向中间收拢补位。
   - `src/sim/world.ts` 与 `src/sim/deployment.ts` 改为按营整体布阵：第一线、第二线（后方 500px）、近卫预备营（后方 720px），同线营间留 `90px`（60～120px）间隔，跨左/中/右三战区部署。
3. **射击操典（C1～C5）**
   - **C1 首轮齐射选择说明**：三列横队首轮齐射采用史实两列齐射操典（第一列跪姿，第二列站立开火，第三列装填递枪不开火），避免第三列从同列正后方误伤站立的第二列；分列轮射时三列依次轮流开火，前排均跪姿让出射界。所有参射士兵开火 tick 严格落在同一个 3 tick 窗口 `[tick+1, tick+3]` 内。
   - **C2 后续射击**：英军（`faction === 1`）默认分排轮射（`platoon`，相邻连间隔 12 tick）；法军（`faction === 0`）默认分列轮射（`rank`，间隔 `cycle / ranks`）。彻底删除 `fireAt` 中的 `w.rng.int(0, 35)` 随机延迟。
   - **C3 自由射击**：仅在营士气动摇（`< 40`）、弹药 `< 25%`、方阵或散兵队形时触发；彻底删除“开火 2700 帧自动转自由射击”。
   - **C4/C5**：营级硝烟 `b.smoke` 同步影响散布；行进中不开火。
4. **交战流程与刺刀冲锋（D1～D6）**
   - 营推进至目标约 `855px`（700～1000px）停下，整队满足连续性或最多等 60 tick 后发射首轮齐射；对射期间原地不动。
   - 彻底删除 `aiDirector.ts:85` 从 2250px 外对满员敌人冲锋的旧规则；严格执行 D4 的 `≤ 400px` 且满足 5 条件之一才下令刺刀冲锋（满足优势条件但距离 > 400px 时先横队压近至 340px 再冲锋）。
   - D5 侧翼 60°～120° 方向 `< 800px` 出现敌军时，营端连自动执行钩形转向（refuse flank）。
5. **其他步兵（E1～E4）**
   - 新增 `Formation = 'skirmish'`（已通过 `grep` 确认 `src/client` 完全兜底，并登记于 `前端待办-Claude.md`），士兵间距 34px 分两列；轻步兵（`voltigeur`）推进时展开于营前 ~405px，敌步兵 ≤ 600px 或敌骑兵 ≤ 900px 撤回营后。
   - 来复枪兵（`rifles`）：有效射程 ×1.5（1500px）、装填 ×1.6、散布 ×0.6，优先瞄准军官（`u.officer`）和炮手。
   - 近卫掷弹兵：首轮齐射推迟至 `≤ 600px`，首轮齐射散布 ×0.75。
