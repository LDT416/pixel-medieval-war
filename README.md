# 拿破仑 1815 · 精品像素线列 v6.0

双击 `dist/index.html` 即可离线游玩。复制游戏时请携带整个 `dist` 目录，封面、兵牌和地图素材都从同级 `art/` 加载。

## 指挥连队

领主对抗中，英法双方按军费自动整编。点下方兵牌可额外招募。线列连满编 30 人，近卫 24 人，重骑 14 骑，重炮组配一门炮和三名炮手，仪仗组三人各持旗、鼓和横笛。

- **全军冲锋**让集结中的连队立即出发。**撤回星堡**将部队召回堡内。**高台驻防**给线列和近卫分配可用的城墙位置。
- 点一名己方士兵选中整个连队，再点目的地下达行军命令。点己方星堡、石桥、农庄或前线炮台可驻防。城墙高地提供 35% 射击伤害、20% 射程和 50% 远程减伤。
- 火枪连举枪后按目标方向齐射，在原地用通条装填。普通线列连折损超过四成会自行溃退，附近的军旗与近卫士气可延后溃退。幸存者以 2.1 倍常速返回星堡，休整并补齐后重新集结。
- 自由沙盒中，点兵牌再点地面即可免费部署整支连队。菜单可切换英法布阵方，也可暂停、倍速、保存和恢复对局。
- 电脑用左键选择或框选，右键或 WASD 平移，滚轮缩放。手机用单指惯性拖动、双指缩放。点击小地图可直接定位。

v6 布阵独立保存。恢复旧版布阵时会按新地图换算位置，把仍适用的部队重编为核心兵种，同时保留军费、战损、要塞生命和地面印记。旧版的经济设施、科技与飞行中的弹药不参与转换。

## 构建与复验

`npm run dev` 启动开发服。`npx tsc --noEmit` 检查类型。`npm run build` 生成支持离线和仓库子路径部署的发行目录。

`npm test` 验证编制与军费、双向齐射、驻防加成、溃逃补兵、火炮与确定性存档回放。安装 Playwright 和 Chrome 后，运行 `node tests/offline.cjs` 核验发行包的素材加载、双击运行、动画与贴花、300 人实战帧率和 390 × 844 触控仿真。可用 `PLAYWRIGHT_MODULE` 指向已有 Playwright 模块。

模拟固定为每秒 30 步，画面由浏览器逐帧绘制并对移动位置插值。核心入口在 `src/sim/world.ts`，连队行为在 `src/sim/strategy.ts`，数值在 `src/sim/config.ts`，像素材质和单位动作分别由 `src/client/artLoader.ts` 和 `src/client/spriteBaker.ts` 接入。
