# 拿破仑 1815 · 千军斗蛐蛐 (HD-2D)

运行 `npm run dev`，用支持 WebGL 2 的浏览器打开终端显示的网址。

默认使用程序绘制的旧立绘。网址加 `?sprites=baked` 可看烘焙版，加 `&seed=23757` 可复现同一场会战。

每局都是一场新的会战：随机的统帅（各有性格）、兵力配比、天气、地形（山脊、石墙农庄、树林），以及可能从侧翼杀到的援军。开战前先看**战前情报**，按赔率用军饷押注一方，或者直接观战。军饷保存在浏览器本地。

## 战斗是怎么打的

- 开局有 12 秒部署时间，默认以四倍播放，可跳过。战前情报卡可查看两军的预定阵位。镜头从各部队进场路线的最后一段开始。左翼、中央和右翼收到不同命令。胜利卡记录预定主攻方向、实际突破位置和首次动用预备队的时间。
- 开战后可以把镜头推近观察一个连。法军三排、英军两排，首轮齐射后按排装填和开火。部分英军连从一翼向另一翼滚射。疲劳、天气和剩余弹药影响后续动作。远程动作在指定帧对棋盘格内的角色结算，角色可以在此之前移出该格。
- 步兵接到冲锋令会先接近目标，约 130 像素处停步，鼓响后跑完最后一段。守方可以用已经装填的射手回击。双方接触后按个体动作和士气继续演算。骑兵接触成形方阵后会后撤重整。
- 地图分左、中、右三个战区。道路、河流、农庄与高地影响移动和交战。传令骑手将总部命令带到各连，后方弹药车供轮换下来的步兵补给。点击战报可把镜头移到事件位置。
- 炮击在落点格结算，弹跳和尘土为视觉效果。
- 一个战区的有效兵力低于原编制的 65%，或平均士气低于 25，就会撤退。丢失两个战区会输掉会战。夺取敌方据点后持续占据多数战略要点也可获胜。战至入夜仍无胜方时按战局天平结算。

界面上有双方士气条、实时“战局天平”（胜率估计）、战报滚动条和大事件标题。**自动导播**会把镜头推到冲锋、溃败、统帅阵亡等关键时刻；手动拖动镜头后，会暂停 8 秒再接管。

左键或右键拖动、WASD 和方向键均可平移。滚轮或 ＋ / － 可以缩放，手机支持双指捏合和双击定位。小地图可点选或拖动。速度最高为 16×，“下一大事”会在下一条重大军情出现时恢复 1×。Home 回到交战中心，空格暂停或继续（情报卡打开时则直接开战），R 开始新战局。网址里的 `?seed=` 是本局种子，分享链接即可让别人看同一场仗；胜利卡上的“重演本局”也会复现它。

## 构建与复验

- `npm test` 跑完 600/1200/1800 三档对局，检查数值有限、坐标不越界、兵力守恒、同种子可复现，以及 1800 人每帧 p99 低于 8 ms，最后统计多个种子的胜负与时长分布（`SEEDS=60 npm test` 可调整局数）。
- `node tests/pace-probe.mjs 23757` 测完整对局的移动、空闲、首次开炮与首次伤亡。`node tests/speedprobe.mjs 23757` 保留旧版采样窗口，适合跨版本对照。
- `node tests/projectile-probe.mjs 23757` 输出格点动作次数、命中与命中友方数，同时检验在结算前移出格子和空格落点。
- `node tests/behavior-probe.mjs` 默认跑 20 局，逐局输出已交班次数、补充弹药数、方阵切换及友方落格计数。
- 启动生产预览和开放本机调试端口的独立 Chromium 后，可设置 `GAME_URL` 与 `CDP_URL` 运行 `node tests/visual-t9.mjs`。它保存 1200 人种子 23757 的两段 10 秒录像、短划最大长度及图集请求记录。
- `node tests/story.mjs <seed>` 打印一局完整的战报时间线，适合调平衡。
- `npm run build` 检查类型并生成 `dist/`，`npm run preview` 提供生产预览。
- `tests/preview.mjs` 在生产预览与独立 Chromium 调试实例上做浏览器级检查；`tests/shot.mjs <seed> <plan.json>` 按计划截图。

## 入口

`src/sim/world.ts` 负责布阵、随机化、援军、胜负判定和赔率（每秒 30 步）。`strategy.ts` 是连队大脑和士兵移动，`combat.ts` 处理齐射、白刃、冲击、炮弹和士气，`aiDirector.ts` 是双方总司令，`maps.ts` 负责地图生成与地形效果。用 `new SimWorld(scale, seed)` 可以复现任意一局。

`src/client/renderer3d/` 管理地形（与模拟共用山脊高度）、农庄与树林立牌、图集、阴影、烟尘、永久贴花和后处理。`window.__arenaDebug.getState()` 可以读取实时兵力、士气、胜率和渲染计数；`startBattle()` 跳过押注直接开战，`world` 暴露模拟对象。

## 炮兵

炮兵在第一线后方约 170 像素展开。前线整体推进 600 像素后，炮组可转移一次，抵达后用 3 秒重新展开。换目标时重新校射，同连共享修正值。雨地缩短滚动距离，晨雾延长校射。
