# 拿破仑 1815 · 线列全面战争 v5.2

双击 `dist/index.html` 进入游戏。复制或部署时携带整个 `dist` 目录，封面、兵牌与战场贴图从同级 `art/` 读取。封面可选择英法两军、三张地图和领主难度。

## 指挥与运营

- 点击兵牌征召一支连队，补齐同兵种的残缺编制。点击兵牌下方的「整团」一次招齐满编部队。长按立绘切换持续征召。沙盒菜单还能切换阵营，选择「沙盒放置」后点地面直接部署整团。
- 点一个士兵选中所属团，点阵型按钮改编，点地面行军。点石屋、风车或己方胸墙可进驻，选中守军再点地面可撤出。空心方阵反骑，刺刀纵队适合近身突击。团旗与鼓手随团行动。
- 线列满编为 120 人。三排依次在第 0、32、64 帧射击，第 96 帧重新循环。首排蹲姿装填。重创的编制撤往星堡集结地或就近炮台休整，随后补入或跟随己方主力。
- 农夫收粮伐木。升级农舍提高人口上限，T2 起农庄发出军需车。占领据点可收取军粮。菜单内可建近卫军营、陆军学院与重炮铸造厂，并研发速装、刺刀和葡萄弹。越过中线或控制拉海圣后可修筑前线炮台。
- 单指拖动后有惯性，双指围绕触点中心缩放。桌面支持左键框选、右键拖动、WASD、滚轮和小地图。
- 菜单包含暂停、倍速、保存、恢复、兵种图鉴、军歌、音效和血腥浓度。v5.2 单独保存进度，首次恢复时可转换原先浏览器中的 v4 布阵。

## 构建与回归

`npm run dev` 启动开发服务器。`npx tsc --noEmit` 检查类型。`npm run build` 输出可离线运行的页面，Vite 使用相对基址，适配 GitHub Pages 仓库子目录。

`npm test` 运行编制、齐射、碰撞、驻守、塌房、撤退、科技、补给和确定性回放测试。构建完成后运行 `node tests/offline.cjs`，以 Chrome 核验实际子路径部署、文件协议运行、桌面操作、390 × 844 触摸手势及贴地效果的像素稳定性。需要 Playwright，可通过 `PLAYWRIGHT_MODULE` 指向已安装的模块。

模拟入口为 `src/sim/world.ts`，兵种与编制在 `src/sim/config.ts`，资源清单与解码在 `src/client/artLoader.ts`。
